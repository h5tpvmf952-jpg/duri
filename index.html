유튜브 + 인스타 미용 콘텐츠 터짐 탐색기
터짐 배율 = 조회수 ÷ 채널 구독자 수 · 떡상 속도 = 조회수 ÷ 업로드 후 경과일. 검색 결과 자체는 YouTube API가 반환한 영상 범위에서 분석돼.
API 키 처음 만드는 법
Google Cloud Console → 프로젝트 생성 → YouTube Data API v3 활성화 → 사용자 인증 정보 → API 키 생성. 키는 이 파일 코드에 들어가지 않고, 저장 버튼을 눌렀을 때 현재 브라우저에만 저장돼.
키를 넣고 검색해줘.
검색 결과가 여기에 표시돼.
Instagram 공식 API의 해시태그 검색 범위 안에서 동작해. 공개 릴스 전체를 무제한 크롤링하는 방식은 아니야. Professional(비즈니스/크리에이터) 계정과 올바른 앱 권한/토큰이 필요해.
Meta 설정에서 필요한 것
Meta for Developers 앱 + Instagram Professional 계정 연결 → 필요한 Instagram API 권한 부여 → Access Token과 Professional Account ID 확보. API 버전은 기본 v24.0으로 넣었고 필요하면 바꿀 수 있어.
Meta 정보 입력 후 해시태그를 검색해줘.
